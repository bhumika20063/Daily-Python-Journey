A Python implementation of the classic Hangman game where players guess letters to reveal a hidden word before running out of lives. This project demonstrates the use of loops, conditional statements, lists, string manipulation, modules, and the random library while building an interactive command-line game.


Features
🎮 Interactive command-line gameplay
🔤 Random word selection
❤️ 6 lives with visual hangman stages
✅ Tracks correct and repeated guesses
🏆 Win/Lose game conditions
📦 Modular code using separate files (hangman_words.py and hangman_art.py)
