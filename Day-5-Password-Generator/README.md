# 🔐 PyPassword Generator

A simple Python project that generates a strong and random password based on user preferences. The user can choose how many letters, numbers, and symbols to include, and the program shuffles them to create a secure password.

## 📌 Features

- Generates random passwords
- User chooses:
  - Number of letters
  - Number of symbols
  - Number of numbers
- Randomly shuffles all characters for better security
- Uses Python's built-in random module
