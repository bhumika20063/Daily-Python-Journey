# Higher Lower Game 🎮

A Python-based command-line game inspired by the popular **Higher Lower** game. Players are presented with two famous personalities, brands, or organizations and must guess which one has more social media followers.

## Features

- 🎲 Randomly selects two accounts for comparison
- 🧠 Tests your knowledge of popular personalities and brands
- 🏆 Tracks your score throughout the game
- ❌ Ends the game when an incorrect guess is made
- 🎨 Interactive console interface with ASCII art

## Technologies Used

- Python 3
- random module
- Functions
- Loops
- Conditional statements
- Lists and Dictionaries
- Modular programming using custom Python files
