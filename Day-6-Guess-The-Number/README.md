# 🎯 Number Guessing Game

A command-line Python game where players try to guess a randomly generated number between **1 and 100**. The game offers two difficulty levels and allows players to replay after winning or losing.

## 📌 Features

- 🎲 Randomly generates a number between **1 and 100**
- ⚡ Two difficulty levels:
  - **Easy** – 10 attempts
  - **Hard** – 5 attempts
- 📉 Displays whether the guess is:
  - Too High
  - Too Low
  - Correct
- 🔢 Shows the remaining attempts after each incorrect guess
- 🔄 Allows the player to play multiple rounds
- 👋 Displays a goodbye message when the player chooses to quit
