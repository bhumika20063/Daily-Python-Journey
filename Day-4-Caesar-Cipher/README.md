This project allows users to encrypt and decrypt messages by shifting letters in the alphabet while preserving spaces, numbers, and special characters.

Features
🔐 Encrypt text using the Caesar Cipher.
🔓 Decrypt encrypted messages.
🔄 Supports positive and large shift values using modulo arithmetic.


Concepts Practiced
Python functions
Loops (for, while)
Conditional statements (if, else)
Lists and indexing
String manipulation
Modulo operator (%)
User input handling
