# 🏝️ Treasure Island

## 📖 Description

Treasure Island is a text-based adventure game. The player navigates through the story by making choices at different stages. Each decision leads to a different outcome, and the objective is to find the hidden treasure.
Making the wrong choice ends the game.
## 🛠️ Concepts Practiced

- Variables
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- Nested Conditions
- String Methods (`.lower()`)
- Print Statements


## 🎯 Learning Outcome

This project helped me practice:
- Writing decision-making logic using nested `if-else` statements.
- Handling user input.
- Building a simple interactive command-line application.
