# ☕ Coffee Machine (Python)

A command-line Coffee Machine simulation built with Python. This project mimics the behavior of a real coffee vending machine by checking ingredient availability, processing coin payments, calculating change, updating resources, and tracking profit.

## 📌 Features

- ☕ Choose from three drinks:
  - Espresso
  - Latte
  - Cappuccino
- 💧 Checks ingredient availability before preparing the drink.
- 🪙 Accepts coin inputs (quarters, dimes, nickels, and pennies).
- 💰 Calculates total payment and returns change.
- 📊 Displays a resource report (water, milk, coffee, and profit).
- 🔄 Updates available resources after every successful order.
- ❌ Handles insufficient ingredients and insufficient payment gracefully.
- 🔌 Supports turning the machine off using the `off` command.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Global Variables
- User Input Handling
